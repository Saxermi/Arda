# Dense linear algebra and reductions

**Status** — Implemented in 0.14.3. Work and storage below exclude inputs unless specified. View packing can allocate a copy of each non-contiguous operand.

## Gaussian elimination and external LAPACK

`nc.solve(A,b)` solves a finite square dense system by Gaussian elimination with partial row pivoting. At column $k$ it chooses $p=\arg\max_{i\ge k}|a_{ik}|$, swaps the remaining row segment and right-hand side, then uses $\ell_{ik}=a_{ik}/a_{kk}$ and $a_{ij}\gets a_{ij}-\ell_{ik}a_{kj}$. It back-substitutes $x_i=(b_i-\sum_{j>i}a_{ij}x_j)/a_{ii}$, accumulating that inner subtraction in `long double`. Work is $O(n^3)$ and a copied matrix plus solution cost $O(n^2)$ storage. The routine does not expose factors, a condition estimate or refinement. An exact-zero pivot is rejected. Partial pivoting controls multipliers and usually yields a small backward error, subject to growth in the elimination. An ill-conditioned matrix can produce a large forward error despite a small residual. [Source, `solve`](../../src/scientific.c) · [Wilkinson 1961](https://doi.org/10.1145/321075.321076) · [Higham 2002](https://doi.org/10.1137/1.9780898718027)

`calc.lapack_solve` can call `dgesv`, which uses pivoted LU and triangular solves. `calc.eigh` checks exact symmetry and calls `dsyev` in eigenvector mode for $A Q=Q\Lambda$. The reference LAPACK driver reduces to symmetric tridiagonal form then solves that eigenproblem and back-transforms eigenvectors. Arda copies to column-major storage, checks `INFO` and queries the eigensolver workspace. The square solve and eigenvectors each take $O(n^3)$ work and $O(n^2)$ storage including the copies and outputs. Eigenvectors in clustered eigenspaces can be sensitive and are assessed by residual, orthogonality and subspace agreement. The concrete kernels depend on the provider chosen at link time. [Source, `calculus_call`](../../src/calculus.c) · [Reference LAPACK routines](https://www.netlib.org/lapack/explore-html/) · [Third-party notices](../../THIRD_PARTY_NOTICES.md)

## Dense products and reductions

`nc.matmul` computes $C_{ij}=\sum_k A_{ik}B_{kj}$ in $O(mkn)$ time with $O(mn)$ output and constant local native workspace on packed inputs. The default path uses row-major blocking, scalar tails, and SSE2 or runtime-dispatched AVX2 when available. The optional CBLAS build calls `cblas_dgemm`. Float64 sums are rounding-sensitive and backend order or contraction can affect results. See the kernel note for dispatch details and the 0.18 baseline. [Source, `multiply` and `matmul_avx2`](../../src/scientific.c) · [Lawson et al. 1979](https://doi.org/10.1145/355841.355847) · [Goto and van de Geijn 2008](https://doi.org/10.1145/1356052.1356053) · [Kernel details](transforms-and-kernels.md)

`nc.dot` and `high.inner` use four extended-precision accumulators for $x^Ty$. `nc.sum`, `nc.mean` and `high.sum_axis` use extended accumulation with no compensated summation guarantee. The portable norm scales the sum of squares, evaluating $s\sqrt{\sum_i(x_i/s)^2}$ with a running scale $s$ so the initial squaring does not cause needless overflow or underflow. Variance uses Welford's online recurrence $\delta_i=x_i-\mu_{i-1}$, $\mu_i=\mu_{i-1}+\delta_i/i$, $M_{2,i}=M_{2,i-1}+\delta_i(x_i-\mu_i)$. The returned variance is the population value $M_{2,n}/n$ and standard deviation its square root. These use $O(n)$ time and $O(1)$ scalar scratch, plus any packed input or axis output. Streaming updates mitigate cancellation in the naïve second-moment formula. The actual precision of `long double` is platform dependent. Min/max are scans, `linspace` interpolates endpoints, and elementwise sin, cos, exp, log and sqrt delegate to the platform math library.
