# Scientific machine learning and low-memory inference

**Status** — Candidates for 0.18 and 0.26. Arda has [scalar AD and optimizer updates](../implemented/optimization-and-ad.md). The first Q4/Q8 and low-precision CPU kernels are [implemented in 0.18.3](../implemented/quantization.md). Model inference and later training milestones remain roadmap work.

| Capability | Baseline and alternatives | Reliability, cost and hardware | Recommended validation |
| --- | --- | --- | --- |
| Neural-network training and scientific models | Start with CPU Float64/Float32 reference layers, stable log-sum-exp, SGD and Adam, then compare AdamW and mixed precision. For scientific ML compare ordinary numerical simulation and inverse-problem baselines with Neural ODEs, PINNs and neural operators. | Dense layer work scales with batch, input and output widths. Reverse mode keeps parameter gradients and live activations. Surrogates can fail outside their training regime or violate conservation. PINN performance depends on sampling, physics and loss weighting. | Moderate effort for small CPU models, high for robust differentiable simulation. Compare analytic derivatives, trajectories, residuals, generalization to unseen parameters and wall time against classical solvers. Report accuracy and resource use per problem, not broad speedups. |
| Transformer inference and streaming | Implement one compatible model with stable online softmax and a full-precision reference. Compare tiled attention, bounded KV cache, mapped layer loads and prefetch. Compare weight streaming with cache residency before expert offloading. | Full attention for sequence length $L$ and hidden size $d$ uses $O(L^2d)$ work. Tiling reduces intermediate memory traffic. KV storage grows with context and KV heads. SSD streaming can be I/O-bound and does not imply real-time 70B inference. | High effort even for CPU. Compare model/tokenizer outputs and logits on small fixtures. Separate prefill, decode, first-token latency, context, persistent storage, RSS and actual I/O. Track model and tokenizer licenses. |
| Quantization extensions and compression | Extend the measured symmetric per-block baseline with asymmetric forms or calibrated scaling. Evaluate GPTQ, learned rotations or KV-cache compression on model workloads. | Packed storage is about $Nb/8$ bytes plus per-block scales/metadata for $N$ values and $b$ bits. Outliers, saturation and rounding affect quality. Dot accumulation needs range analysis. Low-bit formats only help if the CPU can decode and consume data without larger intermediates. | Moderate effort for portable encoding, high for SIMD, calibration and model formats. Measure byte footprint, scalar/vector equivalence, end-to-end throughput and model quality on the same matrix or model. Do not adopt reduced precision implicitly. |
| Fine-tuning and distributed training | Start with LoRA and explicit small-model data parallelism. Compare QLoRA, optimizer-state quantization, gradient low-rank projection, checkpoint/offload, and later sharded states. | Rank-$r$ adaptation stores $O((m+n)r)$ trainable values for each $m$ by $n$ weight, while the base model, forward/backward passes and activations still carry cost. Offload trades transfer and storage for RAM. Distributed gradients require defined weighting, synchronization and determinism. | High effort for device or distributed workloads. Verify frozen weights, optimizer-state updates, gradient equivalence, mixed-precision fallback and checkpoint/restart. Keep one-rank CPU results as the reference before comparing alternative schedules. |

**Research evidence** — Established baselines include Neural ODEs, PINNs, FlashAttention and LoRA. A 2026 preprint studies failure modes of neural operators across PDE families. SpinQuant and PolyQ motivate experiments with learned rotations and CPU-specific quantization design. Their model and platform results require independent Arda measurements.
