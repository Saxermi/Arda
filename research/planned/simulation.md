# Simulation, discretization and scientific domains

**Status** — Extensions and future candidates for Ulmo. The ODE trajectory, fixed-step stiff solvers and Cartesian-grid methods are implemented. [Ulmo contracts and validation](../implemented/ulmo-simulation.md)

| Capability | Baseline, alternatives and cost | Reliability, implementation and tests |
| --- | --- | --- |
| ODE events and output | Keep RK4/RK45 and add a method-consistent continuous interpolant with bracketed event localization. Compare leapfrog or Verlet for separable Hamiltonians. A step uses a constant number of RHS evaluations and $O(d)$ state workspace for $d$ elements. Streaming avoids storing all steps. | Validate event order and grazing events, reverse time, interpolation convergence and long-run energy error. Moderate portable CPU effort. Symplectic stepping is useful under its Hamiltonian splitting assumptions. |
| Stiff integration | Begin with implicit Euler and a safeguarded Newton solve. Compare variable-order BDF and implicit Radau or a provider after the nonlinear contract is established. Direct dense Newton factors cost $O(d^3)$ per rebuild. Sparse or matrix-free costs depend on preconditioning and iteration counts. | Stiff problems can favor implicit schemes despite heavier steps. Validate with Robertson kinetics, van der Pol and stiff modal decay, restart consistency, rejected steps and nonlinear convergence. High effort for adaptive BDF or Radau. |
| PDE and finite elements | Use centered finite differences for smooth diffusion/Poisson, conservative finite volume for flux laws, and linear triangular FEM with variational assembly to CSR. First compare structured tiles, then residual-driven adaptive mesh refinement. Fixed-width stencil apply is $O(N)$ for fixed dimension. Fixed-order FEM assembly is $O(E)$ local work for $E$ elements before canonicalization. | Use manufactured solutions and grid refinement, conservation checks and explicit Dirichlet/Neumann/periodic contracts. Validate CFL restrictions and stiff limits, poor elements and anisotropy. Simple Cartesian CPU methods are moderate effort. Adaptivity and unstructured boundary handling are high effort. |
| Gradients and experiment output | Begin with direct sensitivities for a few parameters and discrete adjoints for many. Compare continuous adjoints against the discrete model and checkpoint state before recomputation. Gradient cost depends on the number of parameters, steps and recomputation schedule. | Validate against finite differences and analytic gradients near event and solver thresholds. Account for stability of reverse integration, checkpoint I/O and state reproducibility. Provider integration and distributed adjoints require substantial additional work. |
| Optional signal processing and geometry | Direct convolution costs $O(NK)$ for an $N$-sample signal and $K$-tap filter. Compare FFT convolution ($O(L\log L)$ after padding) and Mallat's wavelet filter banks ($O(N)$ for fixed filters). For geometric predicates, filtered orientation with adaptive exact fallback helps near degeneracy. | Test padding, phase and boundary conditions, inverse wavelets, degenerate triangles and robust sign selection. These are optional 0.20.5 extensions. Start only when a simulation workload justifies them. |

**Research evidence** — Classical stiff solvers, adaptive FEM estimates and wavelet filter banks remain baselines. Recent mixed-precision Runge–Kutta work motivates separating stage rounding from truncation error in tests. The 2026 DJ4Earth study is a candidate comparison for performance-portable differentiation, with different model and compiler assumptions.
